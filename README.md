# 약·병명 단어장

의학을 전공하지 않은 사람이 병명, 약, 검사 수치, 인체 구조, 의학 용어를 익히는 학습 앱입니다. 한 페이지짜리 웹 앱이고, 설치할 것이 없습니다.

> 공부용 자료입니다. 진단이나 치료, 약 복용을 결정하는 데 쓰면 안 됩니다. 몸에 이상이 있으면 의사나 약사와 상의하세요.

## 들어 있는 것

| 단어장 | 개수 | 내용 |
|---|---|---|
| 병명 | 102 | 암, 감염병을 포함한 흔한 질환의 뜻, 원인, 증상, 치료 |
| 약 | 96 | 성분명, 쓰임새, 작용 원리, 주의할 점 |
| 검사 수치 | 34 | 혈액·소변 검사 항목과 수치 읽는 법 |
| 인체 | 77 | 장기, 뼈, 근육, 피부 구조 |
| 용어 | 61 | 진료 기록과 설명에 자주 나오는 말 |

- **학습 방식**: 카드 넘기기, 퀴즈, 사전 찾기, 인체 보기
- **난이도**: 기초·보통·심화 가운데 고르고, 설명 분량도 짧게·보통·자세히 가운데 고릅니다
- **병변 자료**: 병이 조직에 어떻게 나타나는지 그린 일러스트 25종과 실제 사진 49장
- **진도 기록**: 외운 카드는 브라우저에 저장됩니다

## 3D 인체 보기

- 골격, 장기, 근육, 피부 네 겹을 여러 개 함께 켜고, 바깥 겹의 투명도를 조절합니다
- 머리·목, 가슴, 배·골반, 팔·손, 다리·발 가운데 원하는 부위만 골라 볼 수 있습니다
- 돌리기, 확대·축소, 앞·뒤·옆·위·아래 보기
- 가장 바깥에 보이는 조직마다 이름표가 붙고, 이름을 누르면 설명이 나옵니다
- 남성 모델과 여성 모델을 바꿔 볼 수 있습니다. 여성 모델은 장기와 피부만 있습니다
- 피부 단면도는 표피, 진피, 피하지방, 털집, 땀샘 등을 따로 눌러 볼 수 있습니다

## 실행

파일을 내려받은 뒤 저장소 폴더에서 다음을 실행하고 <http://localhost:8765> 를 엽니다. Node.js만 있으면 됩니다.

```bash
node .claude/serve.js
```

`medical-wordbook.html` 은 Claude 아티팩트용 페이지 조각이라 `<html>` 머리 부분이 없습니다. 위 서버가 그 부분을 붙여서 보여 줍니다. 3D 화면은 three.js r128을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 파일 구성

| 경로 | 설명 |
|---|---|
| `medical-wordbook.html` | 앱 전체 (단어 자료, 화면, 3D 보기) |
| `skeleton.json` `organs.json` `muscles.json` `skin.json` | 남성 3D 모델 |
| `organs-f.json` `skin-f.json` | 여성 3D 모델 |
| `img/` | 병변 사진 49장 |
| `CREDITS.md` | 사진별 저작자, 라이선스, 원본 주소 |
| `tools/` | 3D 모델과 사진을 만드는 데 쓴 스크립트 |
| `.claude/` | 로컬 미리보기 서버 |

### 3D 모델 파일 형식

각 `.json` 은 `{ source, b64 }` 이고, `b64` 를 풀면 다음 순서의 바이너리입니다.

1. `uint32` 머리말 길이
2. 머리말 JSON `{ q, groups: [{ id, nv, ni, u32 }] }` (4바이트 단위로 채움)
3. 조직 묶음마다 `Int16` 좌표(`q` 를 곱하면 미터 단위), 이어서 `Uint16` 또는 `Uint32` 삼각형 번호

### tools

원본 메시를 내려받은 폴더를 인자로 넘겨 실행합니다. 원본 파일은 용량이 커서(1GB 이상) 저장소에 넣지 않았습니다.

| 스크립트 | 하는 일 |
|---|---|
| `pick.js` `pick2.js` | BodyParts3D 부품을 뼈·장기·근육·피부 묶음으로 분류 |
| `build.js` `build2.js` | 남성 모델 단순화와 묶기 |
| `hra.js` `glbinfo.js` `build3.js` | HRA 여성 모델 고르기, 단순화, 크기 맞추기 |
| `commons.js` `commons2.js` | Wikimedia Commons 사진 후보 검색과 내려받기 |

## 알려진 한계

- 여성 모델에는 골격과 근육, 그리고 위·쓸개·갑상샘·귀·부신이 없습니다
- 남성 모델에는 갑상샘·췌장·골수가 없고, 대장 모양이 가늘게 나옵니다
- 일러스트는 구조를 단순하게 그린 것입니다
- 위궤양, 위암, 대장암, 골다공증, 심부전, 통풍, 녹내장 등 일부 병에는 사진이 없습니다
- 휴대전화의 터치 조작은 확인하지 못했습니다
